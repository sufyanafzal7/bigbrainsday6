## About

I build Flutter applications that run machine learning on the device instead of the cloud. My two flagship projects are **ORAS**, a surgical video analysis platform, and **SLCA**, an offline Pakistan Sign Language translator. Both combine a cross-platform Flutter front end with real computer vision and deep learning models.

I'm a BS Artificial Intelligence student at COMSATS University Islamabad, with internship experience at **Horquva** (where I led a nine-person engineering team) and **SafeX Solutions**.

- Currently learning Agentic AI: Claude API, Model Context Protocol (MCP), Agent Skills, and SubAgents
- Currently studying Deep Learning, NLP, and Reinforcement Learning at university
- Open to internship opportunities in Flutter and applied AI

### ORAS (Operative Recognition & Analysis System)
**AI-Powered Surgical Intelligence Platform**

[Repository](https://github.com/sufyanafzal7/oras) | [Live App](https://oras-frontend.onrender.com/) | [Demo Video](https://www.dropbox.com/scl/fi/9rr6s9nsja2vneuqwzvco/ORAS.mp4?rlkey=pbe3v465h1ftt2005ejrsh1ty&st=hqcrogmx&dl=0)

### SLCA (Sign Language Chatting App)
**Pakistan Sign Language Translator**

[Repository](https://github.com/sufyanafzal7/Sign-Language-Chat-App) | [Latest Release](https://github.com/sufyanafzal7/Sign-Language-Chat-App/releases/tag/Latest) | [Demo Video](https://www.dropbox.com/scl/fi/msisv255o5z9hjifpj8ec/MAD-Final-Project.mp4?rlkey=nkcypjm7atjsm4q0ooxx28v3c&st=d671t0vt&dl=0)

`Flutter` `YOLOv8-Pose` `LSTM` `TensorFlow Lite` `Firebase`

- Bidirectional Flutter chat app that translates between Pakistan Sign Language and text in real time
- Fully on-device inference with no cloud dependency
- 80-word LSTM sign recognition model trained on YOLOv8-Pose skeletal keypoints
- Distilled fingerspelling classifier covering 23 letters in a 14.9 KB TensorFlow Lite model
